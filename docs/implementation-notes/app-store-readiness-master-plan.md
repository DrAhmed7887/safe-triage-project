## 2. Mission

Deliver a working, professional, App-Store-submittable SAFE-Triage Lite app **as a Phase-1 demo / decision-support prototype**. Not a medical device. The app must:

1. Build cleanly as a web app and a Hospital Lite PWA.
2. Build, sync, and open in Xcode as a Capacitor iOS wrapper.
3. Have credible release documentation (checklist, metadata draft, privacy policy, demo script).
4. Preserve cross-engine parity (Python ↔ JS).
5. Hold the line on clinical safety (no threshold changes, no safety-floor weakening, no AI override of rules).
